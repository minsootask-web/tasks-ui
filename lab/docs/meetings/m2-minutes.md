## 이식 방식(엔지니어 안 채택)
묶음 단위로 옮긴다: **0 정리 → A 안전 기반(필수, 통째로) → B 즉시 반영·되돌리기 → C 목록 정돈 → D 모바일 손맛 → F 키보드·접근성**, E(표기·말)는 독립. 커밋 단위 cherry-pick은 충돌하므로 묶음별 패치 + lab 전용 코드 제거 목록. 이식 전 관문: node 회귀 테스트 통과, **실기기(iPhone/Android) 확인 1회**, 테스트용 저장소로 30분 사용.
