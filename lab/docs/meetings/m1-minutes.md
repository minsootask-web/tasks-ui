## 합의 원칙
1. **쓴 글은 절대 사라지지 않는다 · 한 항목은 한 곳에만 보인다 · 실패는 쉬운 말과 "다시 시도"로 끝난다.** (디자이너)
2. **파일 형식은 그대로, 화면 표시만 바꾼다.** 섹션 헤더 `## 🔥 High` 등은 봇·Skill이 쓰므로 변경 금지. 형식이 바뀌는 곳은 A5(메모 col을 PC 기준 0~2로 고정)·A6(archive 항목에 `parent` 필드 추가) 두 곳뿐이고 둘 다 기존 데이터와 호환. (엔지니어)
3. **심플함 합격선 = 화면 요소 순감소.** 늘 보이는 새 요소 최대 2개, 시트 안 새 요소 최대 2개, 새로 외울 규칙 최대 2개("길게 누르면 옮기기", "부모 완료 = 하위 완료"). (심플함 수호자)
4. 성공 토스트는 없앤다. 토스트는 **되돌리기**와 **다시 시도** 두 용도만.
5. 커밋 1개 = 항목 1개(감사 ID·기반 ID를 메시지에). 본 서비스로 골라 옮길 수 있게.
