- 일시: 2026-10-20 · 진행: PM · 참석: 디자이너, 심플함 수호자 (엔지니어는 구현 단계에서 검토)
- 사용자 요청(원문): "pc에서 task 추가할 때 묶음 단위(예 : '30일 할일' 하위에 여러가지 항목을 추가)를 한번에 추가할 수 있는 UX 추가해줘."

## 현재 상태
- 하단 입력창(textarea)은 Enter = 추가. 붙여넣은 여러 줄은 **각각 별도 상위 항목**으로 나뉘어 추가됨(2차 회의 R4).
- 하위 할 일은 편집 시트의 `+ 하위 할 일 추가`로 하나씩, 또는 길게 눌러/드래그로 하위로 넣기.
- 심플함 예산: 늘 보이는 새 요소 1개 남음, 새 규칙 0개(2차에서 −2 확보).
- 파일 형식: active.md 하위는 2칸 들여쓰기 `  - [ ] …`. 하위 깊이는 1단계까지(1차 결정).
