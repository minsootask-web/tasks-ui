## 안건 B. 결정이 필요한 UX 쟁점
| # | 쟁점 | 선택지 |
|---|---|---|
| B1 | 되돌릴 수 있는 동작(보관·메모 삭제·Inbox 분류·완료)의 확인창 | ① 유지 ② 확인창 없애고 공용 "실행취소" 토스트 |
| B2 | 모바일 행마다 늘 보이는 ⋮⋮·× | ① 유지 ② ×만 남기고 ⋮⋮는 길게 눌러 드래그 ③ 둘 다 숨기고 왼쪽 스와이프=보관(+실행취소), 길게 누르기=드래그 ④ 둘 다 편집 시트 안으로 |
| B3 | 완료 항목 처리 | ① 현행(줄 긋고 남김 + ⇅ 정렬 + ⋯메뉴 일괄 보관) ② 섹션 아래 "완료 n개" 접기 행(기본 접힘, ⇅ 제거) ③ 체크 후 잠시 뒤 섹션 맨 아래로 이동만 |
| B4 | 탭 이름·언어 | ① 영어 유지(Task/Inbox/Memo/Archive) ② 한국어(할 일/수집함/메모/보관함) ③ 영어 유지 + 나머지 문구만 한국어 정리 |
| B5 | 추가 방식 통일 | ① 현행 ② 하단 입력창을 Inbox·Memo에도 사용, Archive는 추가 없음 ③ FAB 유지하되 Archive FAB만 제거 |
| B6 | 입력창 인라인 우선순위 문법(`!!!`/`!!`/`!`) | ① 넣는다 ② 안 넣는다 |
| B7 | 하위 할 일 만들기 | ① 드래그만(현행) ② 편집 시트에 "하위 할 일 추가" ③ 입력창에서 들여쓰기 문법 |
| B8 | 저장 상태 pill | ① 현행 ② 평소엔 숨기고 저장 중엔 작게, 실패 시에만 강조 + 다시 시도 |
| B9 | 낙관적 업데이트 범위(추가·보관·이동·분류) | ① 체크만(현행) ② 전부 즉시 반영 + 실패 시 되돌림 ③ 추가·보관만 |
| B10 | 우선순위 표기 통일 | 🍅🍋🥝 하나로(Inbox H/M/L, 시트 High/Medium/Low, 토스트 🔥) — 반대 있으면 의견 |
| B11 | 부모 완료 시 하위도 완료 | ① 넣는다 ② 안 넣는다 |
| B12 | 탭 위치 | ① 상단 유지 ② 하단 탭바 |
| B13 | Memo 모바일 스크롤 불가(B1 감사) | ① 길게 눌러 드래그 ② 드래그 핸들 영역 |
| B14 | 기타 감사 항목(대비·터치타깃·링크 자동화·보관 날짜·빈 상태·키보드 접근성) | 포함/제외/보류 |
