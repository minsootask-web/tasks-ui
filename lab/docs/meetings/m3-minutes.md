## E. 묶음(부모 + 하위 여러 개) 한 번에 추가

| 안건 | 결정 | 디·심 | 비고 |
|---|---|---|---|
| E1 입력 방식 | **"한 줄 = 할 일 하나, 들여 쓴 줄 = 바로 위 줄의 하위"** 하나의 규칙. PC: `Shift+Enter` 새 줄(들여쓰기 이어받음), `Tab`/`Shift+Tab`(+`Cmd+]`/`[`) 들여쓰기·내어쓰기 — **입력창이 여러 줄이고 커서가 둘째 줄 이후일 때만**. 한 줄일 때 Tab은 지금처럼 포커스 이동. Enter는 언제나 추가. 하위 1단계까지. 입력창 최대 6줄로 커짐 | 일치 | 거부: "여러 줄이면 첫 줄이 부모", 별도 묶음 시트 |
| E2 붙여넣기 | 같은 규칙으로 해석: `-`·`•`·`*`·번호·`[ ]`·`[x]` 표시 떼고 들여쓰기는 하위로, 3단계 이상은 1단계로. 붙여넣으면 입력창에 정리된 모양으로 보이고 Enter로 추가. 들여쓰기 없는 여러 줄은 지금(R4)처럼 각각 상위 | 일치 | S10(20줄 넘으면 조용히 버림)·S11 함께 해결 |
| E3 안내 | **입력창이 2줄 이상일 때만** 입력창 바로 위 12px 회색 한 줄: `🍅 High에 할 일 1개 + 하위 4개 · Enter로 추가` | 디: 안내 / 심: 없음 → **의장: 안내 채택** | 근거: 사용자가 처음 쓰는 기능이고 들여쓰기 실수를 추가 전에 알아챌 수 있음. 한 줄 입력에는 나타나지 않으므로 평소 화면 영향 0. 소수 의견(심) 기록 |
| E4 모바일 | 해석 규칙은 같음(붙여넣기로 묶음 가능). 키 입력 수단은 PC 전용, 버튼 추가 없음. 모바일에서 직접 만들 때는 시트의 `+ 하위 할 일` | 일치 | |
| E5 실수 복구 | 묶음 = 동작 1개. `Cmd/Ctrl+Z` 한 번에 전부 무름. **2개 이상 한 번에 추가했을 때만 되돌리기 토스트**(모바일엔 Cmd+Z가 없으므로). 되돌리거나 저장 실패하면 들여쓰기 그대로 입력창에 복원 | 디: 토스트 / 심: Cmd+Z만 → **의장: 토스트 채택(여러 개 한 번에 = 일괄 동작, 1차 B1 원칙과 같음)** | |
| E6 우선순위 | 묶음 전체가 입력창 우선순위 버튼의 섹션으로 | 일치 | |

## F. 기본 보기를 "한 목록"으로, 입력창 기본 High

| 안건 | 결정 | 디·심 | 비고 |
|---|---|---|---|
| F1 순서 | **파일 순서 그대로**(High 항목들 → Medium → Low), 섹션 헤더만 없앰. 두 보기의 순서가 같으므로 보기를 바꿔도 항목이 움직이지 않음. 우선순위가 바뀌는 경계에서만 행 간격 10px | 일치 | 파일 형식 불변 |
| F2 우선순위 표시 | **상위 행마다 체크박스와 글 사이 13px 과일(🍅🍋🥝)**, 완료 행은 흐리게. 하위 행·나눠 보기에서는 표시 안 함 | 디: 과일 / 심: 테두리 색 → **의장: 과일 채택** | 근거: 색만으로 구분하면 접근성 기준 미달(노랑 대비), 과일은 tako 정체성이자 이미 쓰는 표기. 남은 "늘 보이는 요소" 예산 1개를 여기에 쓴다 — 섹션 헤더 3개·섹션별 접기 행이 빠져 화면 전체는 순감소 |
| F3 전환 장치 | ⋯ 메뉴 `완료 항목 보관` 아래 한 줄: `우선순위별로 나눠 보기` ↔ `한 목록으로 보기`(다크 모드 항목처럼 문구가 바뀜). 기기에 기억 | 일치 | |
| F4 드래그 | 다른 우선순위 사이로도 끌 수 있고, **놓인 자리 바로 위 상위 행의 우선순위**를 따름(맨 위면 아래 행). 끄는 동안 고스트의 과일이 미리 바뀜. 우선순위가 바뀌었으면 되돌리기 토스트 | 일치(토스트는 디) | 나눠 보기의 "섹션 사이로 옮기면 우선순위 변경"과 같은 규칙이라 새 규칙 아님 |

## 예산 장부(1~3차 누적)
- 늘 보이는 새 요소: 2/2 사용("완료 n개", 행 과일) — 대신 섹션 헤더 3개·섹션별 접기 행이 기본 화면에서 빠짐.
- 새 규칙: 1/2 사용 + 3차 1개("들여 쓰면 하위") — 2차에서 −2 확보분 안. 남은 규칙 예산 1개.
- 이후 새 요소 추가는 원칙적으로 금지. 필요하면 다른 요소를 빼고 넣는다.
