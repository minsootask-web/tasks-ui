## 3. 중점 항목별 확인 (문제 없음 포함)

1. **B9·B1 되돌리기 × 저장 중/실패/409**: `offerUndo`(2969-2980)는 원래 동작이 끝난 뒤에만 반대 연산 → 저장 중 되돌리기·실패 뒤 되돌리기 모두 중복 없음. `fire` 가드로 버튼+Cmd/Ctrl+Z 이중 실행 없음. 토스트 교체 = 이미 저장된 동작이 그대로 확정(설계대로). 되돌리기 연산은 409 때 최신본 위에 한 번만 다시 적용됨. 남은 문제는 R5(결과 모름)·R2(같은 글 오선택)·R11(저널).
2. **B3·B11**: 머무름 중 다시 누르면 취소(3713-3716), 드래그 중엔 다시 그리기 생략, refresh 뒤에도 머무름 유지. B11 되돌리기는 "이번에 같이 완료된 하위"만 미완료로 되돌려 정확함(3718-3732). 남은 문제 R9·R10.
3. **F6**: 마우스는 기존 방식, 터치·펜은 길게 누르기. 8px 넘게 움직이면 취소, 체크·화살표·링크는 제외, contextmenu 막음(4585), `.task` 터치 기기에서 선택·콜아웃 막음(253). 문제는 R3·R7·R13·R22.
4. **B5**: 탭별 초안 유지(4208-4228), 선택 모드에선 입력창 숨김(4231-4234), IME 조합 중 Enter 무시·잔여 문자 제거(4408-4424), Memo Shift+Enter/터치 Enter 줄바꿈. 문제는 R1·R4·R19.
5. **Q1·Q2·Q6·Q8**: 위 2절.
6. **형식 호환**: 새 줄 `- [ ] text`/`- text`, 섹션 헤더 그대로, 메모 순서는 봇과 같은 규칙, archive는 `parent`만 추가 → 봇과 호환. 예외는 R4(줄바꿈이 든 글). 봇 `cmd_done`이 줄을 지워 위쪽 줄이 밀리는 일이 실제로 있어 R2가 현실적임.
7. **XSS**: `innerHTML`에 들어가는 사용자 데이터는 모두 `esc`/`highlightMeta` 경유(2188-2189, 3517, 3602, 3987). 링크는 `https?://`만, URL에 `"`·`'`·`<>`·공백이 못 들어가 속성 탈출 불가, 라벨은 도메인 → **XSS 없음**. 표시 깨짐만 R14. 참고: `esc`는 여전히 따옴표를 바꾸지 않으므로 다른 속성값에 쓰면 안 됨.
8. **접근성·모션**: 시트는 `inert`+포커스 가두기+Esc, tablist 방향키, 체크 후 포커스 유지, prefers-reduced-motion은 CSS 변수·JS(스크롤·깜빡임·하위 체크 튐·접힘) 모두 반영됨. 문제는 R12·R17.
9. **lab 전용 코드 분리**: lab 전용은 `<script src="mock-github.js">`(812)와 init 안 서비스워커 블록(4535-4550, 본 서비스의 `register('sw.js')`를 대체) 두 곳. 이식 때 둘을 되돌려야 하고, localStorage 키 공유(R6)는 꼭 정리 필요. `sw-lab.js`는 `/lab/` GET만 no-store로 넘기고 본 서비스 워커를 건드리지 않아 문제 없음.
