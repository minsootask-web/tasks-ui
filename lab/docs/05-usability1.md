- 일시: 2026-10-20 · 대상: http://127.0.0.1:8765/lab/ (가짜 API)
- 환경: 브라우저 패널, 모바일 375×812(라이트·다크, 터치 기기로 인식), PC 1024×768(라이트)

## 시나리오별 결과

### 1. 출근길 — 할 일 3개 연속 추가 + 하위 2개 (모바일 라이트)
- **성공**
- 탭 수: 할 일 3개 = 우선순위 버튼 4번(🍋→🥝→🍅, 🍅→🍋, 🍋→🥝) + 입력창 1번 + Enter 3번. 하위 2개 = 항목 글 누름 1 + "+ 하위 할 일 추가" 1 + Enter 2 + 닫기 1 = **5번**
- 좋았던 점
  - Enter 뒤에도 입력창이 그대로라 연달아 입력하기 빠름. 화면 밖 섹션(Low)에 들어가면 그 자리로 부드럽게 스크롤하고 잠깐 빛남(토스트 없음). "추가됐나?" 하는 불안이 없음
  - 편집 시트의 "+ 하위 할 일 추가"가 Enter마다 바로 저장되고 다음 입력칸이 이어짐. 드래그 없이 하위를 만들 수 있게 됨(C8 해결)
- 헷갈린 점
  - 우선순위 버튼이 누를 때마다 🍋→🥝→🍅 순서로 바뀜. High로 가려면 2번 눌러야 하고, Medium→Low→High 순서가 머릿속 순서(High→Medium→Low)와 반대라 한 번 더 지나치기 쉬움. 마지막으로 고른 우선순위가 다음 입력에도 남는 것도 처음엔 몰랐음
  - 하위 할 일을 2개 추가한 뒤 **"취소"를 눌러도 하위 할 일은 그대로 저장돼 있음**. "취소" = 이 시트에서 한 일을 무르기로 읽혀서 놀람. 시트 안 하위 목록은 글자만 보이고 고치거나 지울 수 없음
- 버그: [B-6] 아래 참고(섹션 마지막 항목에 하위를 붙이면 active.md에 빈 줄이 끼어듦)
- 심플함: **+1**

### 2. 오전 — 하위 있는 부모 완료, 실수 완료 되돌리기, "완료 n개" 펼치기 (모바일 라이트)
- **성공**
- 탭 수: 부모 완료 1번 → 하위 2개 같이 완료 + 토스트 "하위 할 일 2개도 완료했어요 · 되돌리기". 실수 완료 되돌리기 = **3번**(체크 → "완료 n개" 펼치기 → 체크 해제). 해제하면 원래 자리(섹션 맨 위)로 돌아감
- 좋았던 점: 완료 항목이 0.8초 머물다 "완료 n개" 안으로 접혀 들어가서 목록이 깔끔해짐(C5 해결). 펼친 상태를 기억함
- 헷갈린 점
  - 하위 없는 항목 하나를 완료하면 되돌리기 토스트가 없음. 0.8초 안에 다시 누르는 것 말고는 "완료 n개"를 펼쳐서 찾아야 함. 실수했을 때 "어디 갔지?"가 됨
  - 부모가 미완료인 하위 완료 항목(예: "지난 분기 수치 정리")은 줄 그은 채 그대로 보이고, 완료된 부모는 접힘. 같은 "완료"인데 보이는 방식이 둘
  - 되돌리기 토스트가 목록 위(하단 입력창 바로 위)에 떠서 그 아래 행을 가림
- 심플함: **+1**

### 3. Inbox 정리 — 2개 분류, 1개 보관, 분류 실수 되돌리기, 여러 개 선택 후 취소 (모바일 다크)
- **성공(단, 연타 버그 있음)**
- 탭 수: 분류 1번씩(🍅🍋🥝), 보관 1번(📥), 되돌리기 1번, 선택 2번 + 취소(✕) 1번
- 좋았던 점
  - 누르는 순간 행이 사라짐(낙관적). 토스트 "🍅 High로 보냈어요 · 되돌리기", 되돌리면 원래 자리로 복귀. 확인창 없음(C6 해결)
  - 버튼이 🍅🍋🥝 이모지로 통일, 보관은 📥로 구분(C2·C7 해결). 선택하면 행 버튼이 숨고 하단 바(✕ · n개 선택 · 전체선택 · 🍅🍋🥝📥)만 남음, 입력창도 숨음(B5·B6 해결)
  - 다 비우면 "Inbox를 다 정리했어요 🌮" — 기분 좋음
- 헷갈린 점
  - 행 글자를 누르면 선택만 됨. Inbox 항목 글을 고칠 방법이 아직 없음(C8 일부 미해결)
  - **첫 항목을 선택하는 순간 모든 행에서 버튼이 빠지며 행 높이가 줄어듦** → 두 번째 항목을 누르려던 손가락이 빈 곳을 누름(실제로 한 번 놓침)
- 버그: [B-1] 연타 시 다음 항목까지 분류됨, [B-2] 선택 모드 진입 시 행 높이 변화
- 심플함: **+2**(버그만 빼면 가장 좋아진 화면)

### 4. 우선순위·순서 바꾸기, 하위로 넣기, 보관 → Archive 복구 (모바일 다크)
- **성공(제자리 놓기 버그 있음)**
- 탭 수: 우선순위 변경 = 글 누름 → Low → 저장 **3번**. 순서 = 길게 누름 + 끌기 1회. 하위로 넣기 = 길게 누르고 오른쪽으로 24px 이상 끌기. 보관 = 글 누름 → "보관함으로" **2번**. 복구 = 탭 이동 + ↺ **2번**
- 좋았던 점
  - 모바일 행에서 ⋮⋮·×가 사라져 글 폭이 넓어짐(B2 해결). 길게 누르면 살짝 눌림 예고 → 드래그. 화면 끝 자동 스크롤 있음(B7 해결)
  - "하위로 넣기"는 오른쪽으로 끌 때만 → 순서만 바꾸려다 하위가 되는 사고가 사라짐. 대상 행에 빨간 점선 테두리
  - Archive에 "오늘/어제/3일 전/10/11" 날짜와 하위 개수(+1)가 보임(C9 해결). FAB 없음(C1 해결)
- 헷갈린 점
  - 드래그 중 고스트(끌고 있는 행)가 손가락 바로 아래 대상 행을 덮어서, 점선 테두리가 어느 행인지 알아보기 어려움. 고스트가 화면 오른쪽 밖으로 삐져나감. "하위로 넣기"라는 말이 어디에도 안 나옴
  - 우선순위만 바꾸려고 시트를 열어도 내용 입력칸에 바로 포커스가 감 → 실기기에선 키보드가 올라와 시트를 가릴 것
  - 복구하면 원래 자리(Low 맨 위)가 아니라 섹션 끝으로 감. 복구 뒤 토스트·이동 안내가 없어 "어디로 갔지?"
  - Archive에서 Inbox 출신은 🥚 아이콘. 무슨 뜻인지 설명이 없음
  - 편집 시트에서 우선순위를 바꾸면 완료 항목 뒤 줄에 저장됨(화면엔 문제 없음, md 순서만 어색)
- 버그: [B-3] 제자리에 놓으면 섹션 맨 끝으로 이동
- 심플함: **+1**

### 5. 메모 — 여러 줄 추가, 스크롤, 편집, 빈 메모 지우기, 삭제 후 되돌리기 (모바일 라이트)
- **성공**
- 탭 수: 여러 줄 메모 = 입력창 1 + (Enter는 줄바꿈) + **+ 버튼 1**. 편집 = 메모 누름 1 + 바깥 누름 1. 빈 메모 = 글 지우고 바깥 누름 → 자동 삭제 + "메모를 지웠어요 · 되돌리기". 삭제 = 메모 누름 → × → 되돌리기 **3번**
- 좋았던 점
  - Memo도 하단 입력창으로 통일(C1 해결). 새 메모가 왼쪽 위에 들어감
  - 메모 카드 `touch-action: pan-y` → 메모 위에서도 세로 스크롤 가능, 옮기기는 길게 누르기(B1 해결). ×는 편집할 때만 보임(B4 일부 해결)
  - 비우면 자동 삭제(A10 해결), 되돌리면 원래 열·순서로 복원(PC 3열 번호 `col 2`가 유지됨 → A5 해결 확인)
- 헷갈린 점
  - Task 탭은 Enter = 추가인데 Memo 탭은 Enter = 줄바꿈. 둘 다 키보드 "보내기" 키(`enterkeyhint=send`)라 메모에서 "보내기"를 누르면 줄만 바뀜
  - 편집 중 × 버튼이 20×20px라 손가락으로 누르기 작음
  - 편집을 끝내자마자 다른 메모를 누르면 편집에 들어가지 않은 적이 한 번 있었음(재현 1/2, 원인 미확인)
- 심플함: **+1**

### 6. 지하철(불안정) — 추가·체크·이동 실패
사용한 주입: `__takoMockFail = true`(모든 PUT 500), `{offline:true, method:'*'}`(네트워크 끊김), `{file:'inbox.md'}`(뒤쪽 저장만 실패), `{lost:true, times:1, file:'active.md'}`(저장은 됐는데 응답 유실)

| 상황 | 화면 알림 | 복구 | 판정 |
|---|---|---|---|
| Task 추가 실패(500) | 토스트 "저장하지 못했어요 · 다시 시도", **입력창에 글이 되돌아옴** | + 다시 누르면 저장 | 좋음(A1 해결) |
| 체크 실패(500) | 토스트 + 헤더 알약 "저장 안 됨 · 다시 시도"(빨강) | 알약 누르면 저장됨 | 좋음(A7 해결). 단 체크한 행은 "완료" 안으로 접혀 들어가 "저장 안 된 항목"이 어느 것인지 표시 없음 |
| Inbox 분류 오프라인 | 토스트 "인터넷 연결을 확인해 주세요 · 다시 시도", 행 원래 자리 유지 | 다시 시도 → 정상 이동 | 좋음 |
| Inbox 분류, inbox.md만 실패 | "옮기지 못했어요. 원래 자리에 그대로 있어요 · 다시 시도" | active.md 쪽도 되돌려 **중복 없음** | 좋음(A4 해결) |
| 메모 추가 실패 | "저장하지 못했어요 · 다시 시도", 입력창에 글 유지 | — | 좋음 |
| 저장은 됐는데 응답 유실 | "저장하지 못했어요 · 다시 시도" | 다시 시도해도 중복 안 생김 | 결과는 안전하지만 **문구가 사실과 다름**(실제론 저장됨) |
| 체크 직후 앱 복귀(visibilitychange) | — | 체크 유지·저장됨 | A3 해결 |

- 헷갈린 점
  - 헤더 알약은 Task 저장 실패에만 뜨고 Inbox·Memo 실패에는 안 뜸. 토스트(6초)가 사라지면 Inbox 실패는 흔적이 없음(행이 제자리라 괜찮긴 함)
  - 알약 "다시 시도"는 체크 같은 목록 저장만 다시 함. 추가 실패는 입력창의 + 를 다시 눌러야 함 → "다시 시도"가 두 군데 서로 다른 뜻
  - 알약이 뜨면 헤더의 "남은 할 일 n"이 "남은 …"으로 잘림
- 심플함: **+1**(실패 처리가 조용하고 쉬운 말)

### 7. PC — 키보드만으로 추가·편집·완료, Cmd+Z, hover 핸들 드래그 (PC 라이트)
- **부분 성공**
- 키보드 추가: 입력창으로 가는 단축키가 없음. Tab 순서상 입력창이 맨 끝이라, 첫 Tab부터 가면 행마다 4개(체크·글·⋮⋮·×)씩 지나가야 함(항목 20개 = 80번 이상). 결국 마우스로 1번 눌러야 함
- 편집: 글에 포커스 → Enter로 시트 열림, 내용칸에 포커스 → 수정 → Enter 저장 **성공**. 그러나 **저장 뒤 포커스가 `body`로 떨어짐** → 다시 처음부터 Tab
- 완료: 체크박스에 포커스 → Space **성공**, 포커스가 같은 항목에 남음(D2 해결). 다만 그 항목이 "완료" 안으로 내려가서, 이어서 다음 할 일로 가려면 위로 되돌아가야 함
- Cmd/Ctrl+Z: 보관(×) 직후 Cmd+Z → 복구 **성공**, 확인창 없음. 단 체크·추가·순서 바꾸기는 되돌리기 토스트가 없어서 Cmd+Z가 아무것도 안 함. 입력창에 포커스가 있으면 동작 안 함(의도된 동작)
- hover 핸들 드래그: ⋮⋮로 끌어 "엄마 생신"을 "디자인 리뷰" 위로 **성공**. 핸들에 키보드 이동(↑↓)은 아직 없음(D1 일부 미해결)
- 기타: hover 때 × 버튼이 빨간 채움 원이라 "삭제"처럼 강하게 보임(실제로는 보관)
- 심플함: **0**

### 완성도: **7.5 / 10**
데이터가 사라지거나 두 곳에 남는 문제(감사의 1-A)는 이번 테스트에서 하나도 재현되지 않았고, 실패 안내도 쉬운 말로 정리됐다. 매일 쓰는 흐름(추가·완료·Inbox 분류)은 탭 수가 1~3번으로 짧고 확인창이 사라져 "심플함"이 확실히 살아났다. 감점 요인은 연타·제자리 놓기처럼 **손이 빠를 때 생기는 오조작**과, PC 키보드 동선, 일부 동작의 되돌리기 부재.

### 10점이 되려면
1. **오조작 방지**: 낙관적 삭제 직후 같은 위치 재탭 무시(B-1), 선택 모드 레이아웃 고정(B-2), 제자리 놓기 = 취소(B-3)
2. **되돌리기를 모든 "결과가 사라지는" 동작에**: 단일 완료(완료로 접혀 들어갈 때 "완료했어요 · 되돌리기"), 순서 바꾸기·우선순위 변경·복구. Cmd+Z가 항상 직전 동작을 무르게
3. **PC 키보드 완결**: 입력창 단축키, 시트 닫은 뒤 원래 행으로 포커스 복귀, 핸들 ↑↓·Alt+↑↓ 이동, 완료 후 다음 미완료 항목으로 포커스
4. **편집 시트 다듬기**: 우선순위 직접 선택(컴포저 포함), 자동 포커스는 PC만, 시트 안 하위 할 일 편집·삭제, "취소" 의미 일치
5. **말 정리**: 탭·섹션 한국어화(할 일/수집함/메모/보관함, 높음/보통/낮음 또는 이모지만), 🥚 의미, 응답 유실 시 "저장 확인 중" 문구, 실패 표시를 모든 파일 저장에 연결
6. **실기기 확인**: iOS 홈 화면 PWA에서 키보드·시트 겹침(B9), 실제 손가락 스크롤·길게 누르기 감도(이번엔 JS 흉내로만 확인)
