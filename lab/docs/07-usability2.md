## 시나리오별 결과

### 1. 출근길 — 할 일 3개 연속 추가 + 하위 2개 (모바일 라이트)
- **성공**
- 탭 수: 할 일 3개 = 우선순위 **3번**(🍋→🍅 1번, 🍅→🥝 1번, 🥝→🍋 1번) + 입력창 + Enter 3번. 1차는 우선순위만 4번. 하위 2개 = 글 누름 1 + "+ 하위 할 일 추가" 1 + Enter 2 + 닫기 1 = 5번(같음)
- 좋아진 점
  - 순환이 🍋→🍅→🥝라서 "한 번 = High"가 손에 맞음. 접근성 이름도 "🍋 Medium · 누르면 🍅 High"처럼 다음 값을 알려 줌
  - 시트를 열어도 키보드가 자동으로 올라오지 않음(포커스는 제목 `편집`). 우선순위만 바꿀 때 편함
  - 하위를 추가하면 `취소`가 **`닫기`**로 바뀜 → 1차의 "취소했는데 저장돼 있음" 혼란 해소(B-7)
  - 섹션 마지막 항목에 하위를 붙여도 md에 빈 줄이 안 생김(B-6)
  - 여러 줄 붙여넣기(`- 하나 / • 둘 / (빈 줄) / 1. 셋`) → Enter 한 번에 **3개 항목**, 목록 기호·빈 줄 제거 확인
- 헷갈린 점
  - 붙여넣은 직후 입력창이 여러 줄로 늘어나는데 "3개로 나눠 추가돼요" 같은 예고는 없음. 결과는 기대대로라 큰 문제는 아님
  - 시트 안 하위 목록은 여전히 글자만 있고 고치거나 지울 수 없음(이번 범위 아님)
- 심플함: **+2** (1차 +1)

### 2. 오전 — 부모 완료, 실수 완료 되돌리기, "완료 n개" (모바일 라이트)
- **성공**
- 탭 수: 부모 완료 1번(하위 2개 같이 완료 + "하위 할 일 2개도 완료했어요 · 되돌리기"). 실수 완료 되돌리기 = 3번(체크 → "완료 n개" → 해제). 1차와 같음
- 확인한 것: 체크 뒤 약 0.8초 머무른 다음 `leaving`으로 접혀 들어감. 연속 체크는 마지막 체크 뒤에 한꺼번에 접힘(회의 결정 C1)
- 헷갈린 점: 모바일에서 하나만 완료했을 때 되돌리기가 없는 건 그대로(D2에서 "토스트 추가 없음"으로 결정한 부분, PC는 Cmd+Z로 해결)
- 심플함: **+1**

### 3. Inbox 정리 — 분류·보관·되돌리기·여러 개 선택 후 취소 (모바일 다크)
- **성공**
- 탭 수: 분류 1번씩, 보관 1번, 되돌리기 1번, 선택 2번 + ✕ 1번
- 1차 버그 재확인
  - **B-1 해결**: 두 번째 행 🥝 더블탭 → 그 행만 Low로 감. 사라진 행 자리가 잠깐 빈 칸으로 남았다가 접혀서, 두 번째 탭이 다음 행에 닿지 않음. "회의록 템플릿"은 Inbox에 그대로 있음
  - **B-2 해결**: 첫 항목을 선택해도 행 높이가 그대로(두 줄짜리 행도 두 줄 유지). 두 번째 탭이 정확히 "테스트 항목 나"에 들어감
- 헷갈린 점
  - 사라진 행 자리가 비어 있는 약 0.5초 동안 탭 배지는 아직 이전 숫자(3)
  - 터치 뒤 남는 hover 테두리가 다음 행 🍅에 붙어 보임(눈속임일 뿐 동작 문제는 없음)
  - Inbox 글 고치기는 회의 결정(D4 ②)대로 없음. 분류만 하는 화면이라 납득됨
- 심플함: **+2**

### 4. 우선순위·순서 바꾸기, 하위로 넣기, 보관 → 복구 (모바일 다크)
- **성공**
- 탭 수: 우선순위 = 글 누름 → Low → 저장 3번(키보드 안 뜸). 순서 = 길게 누름 1회. 보관 = 2번. 복구 = 탭 이동 + ↺ 2번
- 좋아진 점
  - 길게 누르는 400ms 동안 행에 `pressing` + 빨간 그라데이션 배경이 차오름(첫 안내 토스트는 없어짐, D8). "곧 잡힌다"가 눈에 보임
  - **B-3 해결**: 잡았다가 제자리로 돌아와 놓으면 아무 변화 없음(md 순서 그대로)
  - 드래그 고스트가 손가락보다 위(실측 행 상단이 손가락보다 50px 위)에 뜨고, 오른쪽 끝 371px로 화면 안에 있음. 하위로 넣을 때는 고스트가 24px 들어가 보임
  - Archive 출신 표시가 🥚 → 11px 회색 **`Inbox`** 글자(D5). 과일=우선순위라는 규칙이 지켜짐
  - Archive ↺ 더블탭 → 1개만 복구됨(B-1 같은 구조도 해결)
- 헷갈린 점
  - 고스트가 손가락 위로 떠도, 손가락 바로 위 행(대상 행 위쪽 절반)을 일부 가림
  - Archive의 `Inbox` 글자 때문에 Inbox 출신 항목만 글 시작 위치가 7px 오른쪽으로 밀려 줄이 들쭉날쭉
  - 복구는 여전히 섹션 끝으로 가고, 복구 뒤 안내가 없음
  - Inbox 탭의 📥 자리와 Archive 탭의 🗑(완전히 지우기, 빨간 채움)가 화면상 **같은 위치**(x≈327, 첫 행). 터치 뒤 남은 hover 때문에 Archive로 넘어오면 첫 행 🗑가 빨갛게 강조돼 보였음. 연속 탭으로 지울 위험은 낮지만 눈에 거슬림
- 심플함: **+1** (1차 +1, 버그 해소로 체감은 더 좋음)

### 7. PC — 키보드·Cmd/Ctrl+Z·hover 드래그 (PC 라이트)
- **대부분 성공**
- 입력창 단축키: **`N` → 입력창 포커스 성공**. 안내 글 "할 일 입력… (/ 키)". `/`는 테스트 도구가 `code="/"`로 보내서 반응하지 않았음(실제 키보드는 `code="Slash"`라 될 것으로 보임). 다만 판정이 `e.code === 'Slash'`뿐이라, `/`가 다른 자리에 있는 자판(예: 독일식 Shift+7)이나 일부 가상 키보드에선 안 될 수 있음 → `e.key === '/'`도 함께 받는 편이 안전
- 편집: 글에 포커스 → Enter → 시트(내용칸 포커스, PC는 자동 포커스 유지) → Enter 저장 → **포커스가 그 행 글로 돌아옴(B-4 해결)**. Shift+Tab 한 번에 체크박스
- 완료: Space → 저장. 포커스는 그 섹션 "완료 n개" 버튼으로 이동(1차는 접혀 들어간 항목에 남음). 다음 할 일로 가려면 위로 되돌아가야 하는 건 비슷
- **Cmd+Z 마지막 동작 되돌리기**: 체크 ✅(그 행 깜빡임 확인) · 우선순위 변경 ✅(원래 자리로) · 순서 바꾸기(⋮⋮ 마우스 드래그) ✅ · 추가 ✅. 단, 추가 직후 포커스가 입력창에 있으면 Cmd+Z는 글자 되돌리기라서 안 먹고, **Esc로 입력창을 빠져나갈 수 없음** → 마우스로 바깥을 누르거나 Tab으로 나가야 함. 체크를 되돌린 뒤 포커스는 "완료 n개" 버튼에 남음
- hover: 행 보관 버튼이 회색 📥(1차 빨간 채움 ×). 빨간 채움은 Archive "완전히 지우기"에만
- 핸들 키보드 이동(↑↓)은 여전히 없음
- 심플함: **+1** (1차 0)

## 전체 평가

### 개선 전(감사) 대비 좋아진 점 Top 5
1. 데이터가 사라지거나 두 곳에 남는 실패가 이번에도 0건. 응답 유실까지 조용히 처리
2. 손이 빠를 때의 오조작이 사라짐: 연타·선택 모드·제자리 놓기 모두 안전
3. 확인창 0개 + 되돌리기(토스트 · PC Cmd+Z 마지막 동작 1개)
4. 모바일 손맛: 길게 누르기 차오름, 고스트 위로 띄우기, 메모 스크롤, 키보드 자동으로 안 뜸
5. 말·동작 일치: 🍋→🍅→🥝, 과일=우선순위·`Inbox` 글자, 취소↔닫기, Memo 줄바꿈 키, 회색 📥 / 빨강=영구 삭제

### 완성도: **9.0 / 10**
1차의 버그 8개가 모두 사라졌고, 새로 찾은 건 전부 "하" 수준(말과 위치의 작은 불일치). 매일 쓰는 동작은 1~3탭, 확인창 없음, 실패해도 글이 남는다. 심플함 예산(늘 보이는 요소)도 늘지 않았다.

### 9.5점 이상이 되려면 남은 것
1. **실패 복구 위치 하나로**: Inbox·Memo 실패도 헤더 알약(또는 Task처럼 버튼 없는 안내)으로 통일, 복구되면 실패 토스트 즉시 닫기
2. **오프라인 문구 구분**: 네트워크 끊김(아무것도 안 됨)과 결과 불명(lost)을 나눠서 "인터넷 연결을 확인해 주세요" / "저장됐는지 확인 중"
3. **PC 키보드 마무리**: `/`를 `e.key`로도 받기, 입력창 Esc = 빠져나가기(그다음 Cmd+Z 가능), 완료·되돌리기 뒤 포커스를 다음 미완료 행/되돌린 행으로
4. **실기기 확인 1회**(회의 관문): iPhone·Android에서 길게 누르기 400ms 감도, 차오름 모션, 고스트 위치, 시트·키보드 겹침, 붙여넣기 분리
5. (선택) 복구를 원래 자리로 + 짧은 깜빡임, Archive `Inbox` 글자 정렬 맞추기
